# Задание для Codex / Cursor: WDeaf Design System Builder, Sprint 01

Ты Senior Frontend Engineer. Создай локальное MVP на React, TypeScript и Vite, опираясь на `components.seed.json` и `figma-audit.md` в этой папке.

Цель первой итерации: визуально понятная веб-страница конструктора для дизайнеров. Функциональный приоритет — точность схемы компонентов и сохранение структуры, а не pixel-perfect воспроизведение Figma.

## Сделай

1. React + TypeScript + Vite. Весь интерфейс на русском. Без backend, регистраций и облачной базы.
2. Трёхколоночная компоновка: каталог (слева), холст (центр), инспектор свойств (справа).
3. Каталог загружается из `components.seed.json`, а не из хардкода. На старте только Button и Input.
4. Добавление в холст кликом, удаление, выбор и изменение порядка. Если drag-and-drop несложен — добавь; иначе сначала реализуй кнопки вверх/вниз.
5. Инспектор динамически строится из `variantProps` и `editorProps` выбранного компонента: enum → select, boolean → checkbox, text → input.
6. Для первого предпросмотра используй приближённые CSS-аналоги; не утверждай, что они пиксельно точны Figma. Поддержи цвета `#0055ff`, `#191f29`, `#ffffff` и Manrope (подключи легально доступный шрифт через обычный веб-источник или fallback).
7. Добавь простой Theme Editor: основной цвет, радиус, шрифт. Эти настройки — локальные overrides, не изменяют Figma-файл. Если значения радиуса/темы не подтверждены Figma, явно обозначь их как дефолты редактора, а не как дизайн-токены WDeaf.
8. Сохраняй CanvasDocument (порядок, компонент, props и тему) в localStorage. Реализуй JSON Export/Import с проверкой формата и schemaVersion.
9. Кнопка «Сгенерировать промпт» должна выдавать структурированное задание для Codex, Cursor, Claude Code: список элементов и настройки, тему, платформу web, ссылку на Figma, ограничения на использование существующих компонентов. Дай возможность скопировать текст.
10. Заложи `ai/` модуль с интерфейсом ChatCommand, но НЕ подключай платную LLM и не имитируй действующий AI-чат. На следующем этапе будем подключать реальный чат, способный менять документ холста.

## Важно

- У Button `hover` и `pressed` — UI-состояния, а не произвольные props React-компонента. `disabled` — свойство поведения.
- У Input Figma `placeholder=true/false` означает наличие placeholder; строка `placeholderText` — наше редактируемое содержимое и хранится отдельно.
- Сначала используем Web. Не реализуй сейчас Android и iOS, но добавь `platform: "web"` в формат документа с возможностью расширения.
- Не создавай лишние типы, свойства или токены, представляя их как факты из Figma.
- Используй отдельные `registry`, `canvas`, `inspector`, `theme`, `prompt`, `storage` модули.
- Покажи дерево файлов и инструкции запуска. Проверь `npm run build`, объясни, что работает, что остаётся заглушкой и какие функции ещё нужны для Sprint 02.

## Критерии приёмки

- Можно создать холст Button + Input, поменять свойства и порядок.
- Холст переживает перезагрузку.
- JSON документ экспортируется и импортируется обратно.
- Промпт отражает реальные props, выбранную тему и порядок элементов.
- Нет сервера, платного API, скрытого расходования токенов и ложных заявлений о точном экспорте из Figma.
