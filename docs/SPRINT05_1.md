# Sprint 05.1 — стабилизация библиотеки

Проверено 04.11.2026 в `feat/ds-component-library`. Schema остаётся v3, контракт обновлён до 1.3.0. Новые семейства и токены не добавлены. Авторизация и Theme Editor не изменены.

## Границы компонентов

`design-system/composition.rules.json` — общий источник разрешённых слотов, внутренних компонентов и родителей для runtime и генератора JSON Schema. Generator проверяет совпадение internal-флагов seed с политикой. TagInput, TagMore и DropdownMenu-строка запрещены в корне в обоих режимах валидации; каталог их скрывает. В Registry 15 записей: 9 корневых (включая legacy Table) и 6 внутренних.

Подтверждённые композиции: Input → Hint/Label; TagGroup → TagItem; DropdownMenu-контейнер → ItemsList → DropdownMenu-строки. Проверяются типы, количество, размеры, согласованность вариантов, глубина и уникальность ID. Источник intended usage — сохранённые descriptions Figma в `ds-coverage-inventory.json`, включая прямое «Не используется отдельно». TagMore генерируется только внутри TagGroup. У TagInput подтверждён родитель TagGroup, но редактируемый слот/состояние ввода в поддержанной матрице не подтверждены: такой слот не добавлен.

Импорт, редакторские изменения, strict renderer, экспорт, сохранение и prompt проходят общую валидацию. Невалидные старые корни автоматически не оборачиваются, не удаляются и не переименовываются. При загрузке показывается причина и приостанавливается автосохранение; исходную строку JSON можно скачать без изменений. Перед явной заменой холста исходник резервируется в `.rejected-backup`. Legacy v1/v2 при нормальном сохранении по-прежнему резервируются в `.pre-v3-backup`.

## Интерактивность и сохранения

Select хранит `interactionState: { selectedValue: string | null }`. Это необязательное состояние документа Builder, **не Figma prop**. Старые v3 без него читаются без изменения. Значение должно присутствовать в optionsText; неизвестные поля и состояние на другом компоненте отклоняются. Для изменения списка с удалением выбранного пункта сначала доступен явный сброс выбора в Inspector. Значение сохраняется в обоих preview, JSON, prompt, localStorage и после reload. Одинаковые текстовые пункты имеют одно значение; отдельные option IDs и multiselect не вводились.

У closable TagItem крестик удаляет элемент существующим действием Canvas; disabled не удаляется. У TagGroup разрешены только подтверждённые переходы **1 → 2** (Add Tag) и **2 → 1** (удаление, если closable). Создаваемый тег имеет исходную подпись Label, которую можно изменить в Inspector. ID и содержимое оставшихся тегов сохраняются. Ноль и более двух тегов, свободный ввод с commit и расширенная TagInput-композиция не реализованы: такие варианты потребовали бы расширения проверенной матрицы. При границе диапазона декоративные элементы источника не выдают неподдерживаемое действие за работающее.

## PR и публичная демоверсия

Ветка основана на `3a2a12b` (Sprint 04/Contract), который основан на main `7bd90fd`. Sprint 05 ранее был незакоммиченным рабочим деревом; коммит стабилизации включает его файлы, источники Figma и отчёт аудита. Один PR Library → main включает и Sprint 04; отдельный merge renderer не нужен.

Добавлен `check.yml` для pull_request: npm ci, typecheck, DS, server build, tests, Pages build/check и переносимые браузерные проверки. Он не публикует сайт. Существующий deploy.yml не изменён этой стабилизацией. Полные screenshot baselines — macOS; Linux CI запускает поведенческие сценарии, а не подменяет эталоны.

Откат сайта на старый main не делает новые v3 читаемыми старым v2 importer. Перед откатом нужно экспортировать v3 и отдельно сохранить legacy backup; backup не содержит изменений после миграции. Автоматический lossless downgrade не заявляется. Merge выполняет пользователь после ревью и CI.
