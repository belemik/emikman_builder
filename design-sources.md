Источник: тот же Figma-файл `wiJYO9bWctpEiq2STFkNYU`; проверенные значения — `tokens.verified.seed.json`, схемы новых компонентов — `components.sprint02.seed.json`.

SVG сохранены локально без изменения содержимого. Цветовой override Checkbox применяется CSS к оригинальному SVG; он не объявляется новым токеном Figma. Извлечённые ранее SVG Switch в public/ds не подключены: каталог Sprint 02 содержит только Button, Input, Select, Checkbox и Table.
