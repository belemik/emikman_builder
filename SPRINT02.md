# Sprint 02 — результат

Работа выполнена в существующем React + TypeScript + Vite проекте. Git не инициализирован: ветка не создавалась. Исходники до изменений сохранены в `.backups/before-sprint02-source.tar.gz` (без `.data` и зависимостей). Сервер авторизации, логины и сессии не менялись.

## Изменения

- `src/registry/index.ts`: Button/Input из исходного seed сохранены, Select/Checkbox/Table добавлены из Sprint 02. Всего 5 уникальных типов. Table имеет пустые корневые variantProps; 14 типов ячеек, color и cell-divider остаются в childComponentMetadata.
- `src/tokens/index.ts`: 20 проверенных токенов, неизменяемый реестр и сведения об их происхождении. Не полный экспорт.
- `src/theme/model.ts`, `src/theme/index.tsx`: themeOverrides, разрешение базовой темы, HEX-валидация, радиус 0–32, шрифт с системным fallback; «Сбросить настройки» возвращает дефолты редактора (радиус 8), «Восстановить WDeaf» очищает overrides. Оформление приложения в профиле не меняется.
- `src/canvas/model.ts`, `src/storage/index.ts`: документ v2 и миграция v1; ключи localStorage остались прежними, привязка к аккаунту сохранена. До первого сохранения v2 исходный v1 копируется в `<старый ключ>.sprint01-backup`. При ошибке создания резервной копии сохранение не выполняется.
- `src/canvas/Preview.tsx`, `CheckboxPreview.tsx`, `SelectPreview.tsx`, `TablePreview.tsx`: новые preview. Checkbox интерактивен, checked/indeterminate сохраняются. Select доступен с клавиатуры, поддерживает раскрытие вверх/вниз, boolean label/placeholder и disabled. Table содержит заголовок, шапку и три строки из seed.
- `src/main.tsx`, `src/inspector/index.tsx`: пять карточек каталога, режимы «Свойства» / «Тема», многострочный optionsText, описание составной таблицы, миграционные сообщения.
- `src/prompt/index.ts`, `src/ai/index.ts`: промпт с component IDs, порядком, Figma verified, editor content, токенами и Editor override; контракт AI обновлён под themeOverrides, LLM не подключена.
- `src/account.tsx`, `src/ui/index.tsx`, `src/ui/CatalogSample.tsx`, `src/ui/styles.css`, `src/appearance/appearance.css`: Avatar вместо текстовой кнопки профиля, ButtonClose вместо «Закрыть», оригинальные иконки действий. Механизм входа/выхода не изменён.
- `public/icons/`, `public/ds/`: оригинальные SVG из Figma, локальные ссылки и исходные размеры. Avatar и ButtonClose используются в оболочке, не расширяют каталог за пределы пяти типов. Ранее скачанные ресурсы Switch пока не используются.
- `tests/document.test.ts`, `tests/sprint02.test.ts`: миграция, round-trip, новые схемы, immutable tokens, восстановление темы, safe text, table metadata и backup. Существующие `tests/auth.test.mjs` сохранены.
- `.gitignore`, `README.md`, `design-sources.md`, `SPRINT02.md`: резервная копия исключена из Git, инструкции и ограничения актуализированы.

Входные `CODEX_TASK_02.md`, `figma-audit-02.md`, оба компонентных seed и tokens seed не переписывались. Новые зависимости не устанавливались, package.json не менялся.

## Ограничения

1. Старый радиус v1 от 33 до 48 при миграции ограничивается 32. Показывается сообщение; исходное localStorage сохраняется в backup, исходный импортируемый файл не меняется. Если требуется восстановить именно прежний внешний вид с радиусом >32, используйте резервную версию приложения и исходный JSON.
2. Preview остаётся приближённым. Оригинальные SVG и отдельные образцы извлечены, но полная геометрия, все темы Figma и Code Connect не реализованы. Цветовые/геометрические overrides — настройки редактора, не новые токены.
3. Select хранит список вариантов в optionsText; сделанный на preview выбор временный и не экспортируется. После перезагрузки и изменения props он сбрасывается. Input filled по-прежнему демонстрационный.
4. Table — составной паттерн на тестовых данных. Редактируется заголовок; действия строк демонстрационные, 14 вариантов table-cell не реализованы как отдельные визуальные типы и не выданы за свойства Table.
5. Checkbox indeterminate показывается как mixed независимо от checked. При клике mixed снимается. Это редакторская интерпретация комбинации indeterminate=true/checked=false, которой нет среди исходных Figma-узлов, но которая допускается предоставленным Sprint 02 seed.
6. Нет облачной синхронизации, совместного редактирования или новой логики авторизации. Холсты локальны для браузера и аккаунта.
